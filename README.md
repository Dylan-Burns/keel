# Keel

Grounded answers to business questions about SEC 10-K and 10-Q filings, from
exactly one model call per question, with citations that the service checks
against the filing text before it shows them.

This file is the stage 0 placeholder. Stage 22 writes the full README from
the outline in `docs/23_readme_outline_and_repo_hand_off_checklist.md`.

- Plan: `docs/01_*.md` to `docs/29_*.md`
- How the build runs: `START_HERE.md`, `CLAUDE.md`, `docs/STAGES.yaml`
- Build log: `docs/BUILD_REPORT.md`

Corpus facts (`keel inventory`): 246 filings of 54 companies, 89 10-Ks and
157 10-Qs, filed February 2022 to February 2026, plus 1 GE file from 2015.
The manifest description claims 15 companies with full quarterly coverage
for 2023-2025; the files show 12 (E-D-25).
